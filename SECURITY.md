# Security Policy

## Supported versions

Security fixes are provided for the latest version available through the Chrome
Web Store and Firefox Add-ons. Update to the latest store version before reporting
a problem that may already have been resolved.

## Report a vulnerability privately

Do not open a public issue for a suspected vulnerability. Email
[slowedandreverbsupport@proton.me](mailto:slowedandreverbsupport@proton.me) with:

- the affected browser and extension version;
- a concise description of the impact;
- the shortest reliable reproduction steps; and
- any proof of concept with secrets and personal data removed.

For ordinary bugs and feature requests, use the public issue tracker described in
[SUPPORT.md](SUPPORT.md).

## What to expect

You will receive an acknowledgment, followed by an assessment or a request for
additional information. Please allow time to investigate before disclosing the
issue publicly. This project does not currently operate a paid bug-bounty
program.

## Scope

This policy covers the extension as published in the stores and the website at
slowedreverbapp.com.

The extension and the website ship none of this project's npm packages; those
are development tools for building, linting and testing. Advisories in them
that have been reviewed and found not to reach this project are listed, each
with its reason and a date to look at it again, in
[audit-exceptions.json](audit-exceptions.json). If you find a way this
project's own use does reach one, report it privately as described above.
